# Русификатор ArcheAge Chronicles Demo

Неофициальный русский перевод текста демоверсии из Steam. Переведены интерфейс, диалоги, задания, предметы и описания. Перевод дорабатывается по замечаниям игроков: отдельные надписи и размеры текста ещё требуют проверки. Озвучка остаётся прежней.

**Версия перевода: 8. Комплект: 8.1. Совместимость: Steam Demo, сборка 26020644.** Для полной версии игры этот комплект не проверен.

## Установка

1. Закройте игру и распакуйте ZIP с русификатором.
2. Скопируйте **всё содержимое архива в папку игры**, где находится `ArcheAgeChronicles.exe`. Подтвердите слияние папок и замену файлов.
3. В папке игры дважды нажмите **`Enable-Russian.cmd`**, дождитесь сообщения об успехе и запустите игру через Steam.

Рядом с EXE должны оказаться папки `Engine`, `X5`, `tools`, файлы `Enable-Russian.cmd`, `Disable-Russian.cmd` и `release-manifest.json`. Сам EXE уже установлен вместе с игрой и в комплект русификатора не входит.

`Enable-Russian.cmd` один раз выбирает русский язык в настройках текущего пользователя Windows. Остальные настройки и озвучку он сохраняет. Программа не запускает игру и не требует установки дополнительных программ.

## Выключить русский язык

Закройте игру и запустите **`Disable-Russian.cmd`** в её папке. Он выберет английский язык, сохранив файлы перевода, озвучку и остальные настройки. Чтобы вернуть русский, запустите `Enable-Russian.cmd`.

**Оба файла откажутся менять настройки, пока запущена игра или её загрузчик.** Самостоятельно закрывать игру они не будут.

Если ранее добавляли **`-culture=ru`** в параметры запуска Steam, удалите этот параметр при отключении русского — иначе он может снова включить русский при запуске. Скрипты параметры Steam не меняют.

## Если игра осталась на английском

В свойствах игры в Steam добавьте в **параметры запуска**:

```text
-culture=ru
```

Если там уже есть другие параметры, сохраните их и добавьте этот через пробел. Затем запустите игру снова. Ранее работа перевода была подтверждена с этим параметром и сохранённым русским языком; отдельная проверка чистой установки без параметра ещё не выполнена.

## Обновление перевода

Закройте игру и скопируйте файлы новой версии поверх старых. Если язык уже русский, повторно запускать `Enable-Russian.cmd` не требуется.

Переключение языка не удаляет русификатор и не восстанавливает прежние версии файлов. Совместимость с другими сборками игры пока не проверена.

## Сообщить об ошибке

Создайте Issue в этом репозитории: приложите скриншот, опишите место в игре и укажите версию русификатора. Для длинных или обрезанных надписей желательно показать окно целиком.
